Rangkuman Materi

Jenis-Jenis Cyber Attack

Eksplorasi ancaman keamanan siber dan cara kerjanya

01

Clickjacking

Pengertian: Teknik jebakan visual menggunakan lapisan transparan (iFrame) di atas halaman web.

Cara Kerja: Korban merasa mengeklik tombol biasa, padahal mengeklik tindakan tersembunyi seperti mengizinkan akses kamera/lokasi.

02

Phishing

Pengertian: Penipuan dengan berpura-pura menjadi pihak resmi atau terpercaya.

Cara Kerja: Pelaku mengirim pesan atau tautan palsu untuk mencuri data sensitif seperti username dan password.

03

Identity Theft

Pengertian: Pencurian data pribadi (NIK, KTP, nama ibu kandung) untuk disalahgunakan.

Cara Kerja: Data yang dicuri digunakan untuk mengajukan pinjaman online palsu atau penipuan atas nama korban.

04

Social Engineering

Pengertian: Manipulasi psikologis manusia agar menyerahkan informasi sensitif.

Cara Kerja: Berfokus pada titik lemah manusia, misalnya menyamar sebagai petugas bank yang meminta kode OTP.

05

Credential Stuffing

Pengertian: Serangan yang memanfaatkan kebiasaan menggunakan password sama di berbagai akun.

Cara Kerja: Pelaku mencoba data login dari bocoran satu situs untuk membobol akun di situs lain.

06

DDoS Attack

Pengertian: Membanjiri server dengan trafik palsu hingga sistem tidak dapat diakses.

Cara Kerja: Menggunakan jaringan botnet untuk menyerang server hingga tumbang.

07

Brute Force Attack

Pengertian: Metode mencoba kombinasi kata sandi secara berulang.

Cara Kerja: Menggunakan software khusus untuk menebak password secara otomatis.

08

Eavesdropping Attack

Pengertian: Penyadapan komunikasi digital secara diam-diam melalui jaringan.

Cara Kerja: Menyadap lalu lintas data pada Wi-Fi publik yang tidak aman.

09

Man-in-the-Middle (MitM)

Pengertian: Menyusup di tengah-tengah jalur komunikasi dua pihak.

Cara Kerja: Pelaku menyadap dan dapat mengubah isi pesan tanpa disadari korban.

10

Typosquatting

Pengertian: Pembuatan situs web palsu yang memanfaatkan kesalahan ketik domain.

Cara Kerja: Mengarahkan pengguna yang typo (misal: shope.com) ke web jebakan untuk mengambil data.

11

Insider Threat

Pengertian: Ancaman keamanan yang berasal dari internal organisasi.

Cara Kerja: Dilakukan oleh pegawai/pihak ketiga yang punya akses ke sistem internal.

12

SQL Injection

Pengertian: Eksploitasi celah keamanan pada basis data (database) situs web.

Cara Kerja: Menyuntikkan perintah SQL khusus pada form input untuk mengambil atau merusak data.

13

DNS Poisoning

Pengertian: Peracunan cache pada DNS Server dengan informasi IP palsu.

Cara Kerja: Mengalihkan pengguna yang mengetik URL asli ke situs web palsu.

14

Drive-by Download

Pengertian: Perangkat terinfeksi malware secara otomatis hanya dengan mengunjungi web tertentu.

Cara Kerja: Malware terunduh otomatis tanpa perlu mengklik tombol apa pun.

15

Cross-Site Scripting (XSS)

Pengertian: Penyuntikan skrip kode jahat ke dalam situs web terpercaya.

Cara Kerja: Skrip berjalan di browser pengunjung untuk mencuri data sesi/cookie.

16

IoT Exploitation

Pengertian: Eksploitasi celah keamanan pada perangkat pintar terhubung internet.

Cara Kerja: Mengambil alih CCTV/Smart TV untuk meretas jaringan rumah.

17

Zero-Day Exploit

Pengertian: Serangan pada celah aplikasi yang belum diketahui oleh pengembang.

Cara Kerja: Memanfaatkan celah sebelum perbaikan/patch keamanan dirilis.

18

Supply Chain Attack

Pengertian: Serangan tidak langsung yang menargetkan vendor/pihak ketiga.

Cara Kerja: Menyisipkan malware ke update software resmi dari penyedia terpercaya.

Kesimpulan

Serangan siber sangat beragam, mulai dari memanipulasi manusia (Social Engineering), memanfaatkan kelalaian (Typosquatting), hingga mengeksploitasi celah teknis sistem (SQL Injection, Zero-Day Exploit). Keamanan digital bergantung pada kombinasi sistem pengamanan yang kuat dan kewaspadaan pengguna.
